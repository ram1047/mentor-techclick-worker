# Techclick Mentor Desk

People in networking pick a mentor and pay for a week or a month. Mentors apply, set both prices, and keep 80 percent. Techclick keeps 20 percent.

Live site: https://mentor.techclick.in

```bash
npm install
npm run check
npm run dev
```

The private desk key is a Cloudflare secret named `DESK_KEY`. It is not in this repo. Open https://mentor.techclick.in/desk and paste the key.
